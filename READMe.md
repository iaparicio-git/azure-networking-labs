## Overview

This lab explores how to control network traffic routing within Azure Virtual Networks using User Defined Routes (UDRs) and Network Virtual Appliances (NVAs).

A custom route is configured on a public subnet to direct traffic destined for an internal private subnet through a perimeter network subnet, where an NVA will be deployed. This demonstrates how to implement centralized traffic inspection and routing through a network appliance.

## Objectives

1. Understand how User Defined Routes (UDRs) control traffic flow within Azure Virtual Networks.
2. Create a custom route to direct traffic from a public subnet toward a perimeter network subnet.
3. Configure the route to use an NVA as the next hop.
4. Understand how NVAs support centralized network traffic inspection, monitoring, and security.
